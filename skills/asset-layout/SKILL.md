# 素材文件结构

## 目录

每个内容单元（一集、一篇文章）一个目录，素材平铺在 `assets/` 下：

```text
EP01-接龙机器/
├── 稿.md
├── 配图.md
└── assets/
    ├── F03-转移表.drawio     # 源文件
    ├── F03-转移表.png        # 成品
    ├── F04-转移图小球.tsx
    ├── F04-转移图小球.mp4
    ├── F04-转移图小球.png    # 视频封面 / 文章用图
    ├── F02-奥涅金计数.肖像.jpg   # 下载的图
    ├── F02-奥涅金计数.肖像.md    # 它的来源和授权
    ├── F13-本质主义.md       # AI 插画的 prompt（源文件）
    └── F13-本质主义.png
```

## 命名

- `F##-短名.扩展名`：镜号从 F01 起，按在稿中出现的顺序，两位数字；短名 3–8 个汉字或英文词。
- **源文件和成品同名，只靠扩展名区分。** 成品永远能由源文件重新导出。
- 没有可导出源文件的图（下载的、AI 生成的）：配一个同名 `.md`，记录来源、授权或 prompt。
- 一个镜号有多个文件时用后缀：`.肖像`、`.书页`（多张原图），`.v1`、`.v2`（AI 候选），`.9x16`（其他画幅）。
- 禁止空格、`图1.png`、`final_v3.png`。

## 配图.md

```markdown
| 镜号 | 文件 | 形式 | 画面（一句话） | 状态 | 来源 |
|---|---|---|---|---|---|
| F03 | `assets/F03-转移表` | 示意图 | 2×2 转移表 + 状态转移图 | 草稿 | 自绘 |
```

- 文件列只写到短名，不带扩展名（同名的源文件和成品都属于它）。
- 状态：`待制` → `草稿` → `定稿`，或 `作废`。
- 来源：`自绘`、`自摄`、`AI`、`公有领域`、`CC BY-SA 需署名` 等简称；细节在同名 `.md` 里。
- 稿子里用 `【配图 F03】……` 标记位置。

## 改动规矩

- 新增：下一个镜号接着编。
- 作废：状态标 `作废`，文件移到 `assets/_废弃/`，镜号不复用。
- 不改写 `稿.md` 正文，最多提醒用户哪里需要同步。
